## 七、面试题整理

### 7.1 概念理解类 🌱

**Q1：为什么行为示范对Staff Engineer特别重要？**

**答案：**

**原因分析：**

| 原因 | 说明 |
|-----|-----|
| **影响力来源** | Staff Engineer的正式权力有限，主要靠影响力 |
| **文化塑造** | 团队会模仿领导者的行为 |
| **信任建立** | 言行一致是信任的基础 |
| **标准设定** | 领导者设定团队的行为标准 |
| **代际传承** | 新人通过观察学习 |

**关键点：**
- 你做什么比你说什么更重要
- 团队会观察你如何处理困难情况
- 你的行为会影响整个团队的价值观

**Q2：如何在团队中建立信任？**

**答案：**

**建立信任的方法：**

```mermaid
%%{init: {"graph": {"defaultLayout": "td", "rankdir": "TB"}, "subGraph": {"ranksep": 80}}}%%
graph TD
    subgraph 建立信任["建立信任的关键行动"]

        T3[承认错误] -->|"不推卸"| B3
```

**具体做法：**

4. **承担责任** - 出了问题首先反思自己
5. **持续一致** - 长期保持相同标准

### 7.2 实践应用类 🌿

**Q3：你发现团队中有不道德的行为（如数据造假），你会怎么处理？**

**答案：**

**处理步骤：**

```mermaid
%%{init: {"graph": {"defaultLayout": "td", "rankdir": "TB"}, "subGraph": {"ranksep": 80}}}%%
flowchart TD
    A[发现不道德行为] --> B[确认事实]
    B --> C{严重程度?}
    C -->|"轻微"| D[私下沟通]
    C -->|"严重"| E[正式报告]
    C -->|"违法"| F[立即报告合规]

    D --> G["提醒并解释为什么不对"]
    E --> H["向管理层/合规报告"]
    F --> I["确保法律合规"]

    G --> J[跟踪改进]
    H --> J
    I --> J
```

**处理原则：**
1. **确认事实** - 不要基于传言行动
2. **选择合适的方式** - 私下vs公开
3. **保护举报人** - 如果有人举报
4. **遵守流程** - 遵循公司政策
5. **坚持原则** - 不因压力妥协

**Q4：如何在高期望下保持心理健康？**

**答案：**

**保持心理健康的策略：**

| 策略 | 具体做法 |
|-----|---------|
| **设定边界** | 明确工作时间和休息时间 |
| **寻求支持** | 与导师、同事、家人交流 |
| **自我关怀** | 保持运动、睡眠、爱好 |
| **分解压力** | 将大压力分解为小问题 |
| **保持视角** | 长远看，当前的困难是暂时的 |
| **专业帮助** | 必要时寻求心理咨询 |

## 十、本章小结

### 核心收获

1. **行为示范是最有力的影响力**
   - 团队会观察并模仿领导者
   - 言行一致建立信任
   - 涟漪效应影响整个组织

2. **信任需要持续建立**
   - 能力信任、诚信信任、善意信任
   - 兑现承诺、保持透明、承认错误
   - 信任破坏后需要时间和行动修复

3. **职业操守是底线**
   - 诚实、负责、公正、保密
   - 在压力下坚持原则
   - 建立伦理决策框架

4. **压力管理是持续挑战**
   - 识别压力来源
   - 建立支持系统
   - 保持身心健康

5. **持续学习是榜样责任**
   - 公开学习过程
   - 积极分享知识
   - 制定发展计划
